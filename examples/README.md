# A real investigation export

investigation.json is a reproducible default comparison for Katarapko station A4261108 and radar area candidate-2, using HH power, zero lag, a one-day window and retrospective observations. It contains actual acquisition/ground timestamps, distances, means and the insufficient-data verdict. It is not a forecast or a simulated dataset.

Run the application and use **Export investigation** to create other comparisons. See REPRODUCIBILITY.md for regenerating the analysis and a native radar pair configuration. Keep generated local configurations under ignored outputs/local because they resolve your configured raw-data location.
